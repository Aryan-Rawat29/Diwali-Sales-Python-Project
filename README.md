Diwali Sales Analysis — Python EDA Project
Exploratory Data Analysis on Diwali Sales dataset to uncover customer buying patterns and revenue insights.
Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn
Analysis Performed

KPIs — Total Sales, Total Orders, Sales Per Order
Gender-wise & Marital Status-wise Revenue
Top 5 States by Revenue
Age Group + Gender wise Revenue (Teenage, Adult, Senior, Senior Citizen)
Top 5 Product Categories by Revenue

Dataset
Diwali Sales Data | Columns — Gender, Age, State, Orders, Amount, Product Category
